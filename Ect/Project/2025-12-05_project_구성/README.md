# 🥐 대동빵지도(Daebbangmap)

AI 기반 사용자 취향 추천과 지도 검색을 지원하는 **빵집 탐색 서비스**입니다.  
사용자는 카테고리별 빵집을 필터링하고, 마음에 드는 가게를 즐겨찾기하거나 리뷰를 작성할 수 있습니다.  

---

## 📌 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **서비스명** | 대동빵지도 |
| **목표** | 빵집 탐색, 취향 기반 추천을 결합한 로컬 맛집 플랫폼 |
| **주요 기능** | 카테고리별 필터링, 지도 검색, 리뷰 작성, 즐겨찾기, AI 추천 |
| **기술 스택** | Frontend: Vue.js<br>Backend: Django<br>API: Kakao Map API, OpenAI API |
| **참고 데이터** | 공공데이터포털(제과점 리스트) |

## ⚙️ 주요 기능

### 기능적 요구사항
| 코드 | 기능명 | 설명 | 우선순위 |
|------|---------|------|-----------|
| F01 | 빵 카테고리 | 식사빵, 페이스트리, 케이크, 쿠키류 등 세분화된 카테고리로 분류 및 리스트 제공 | 높음 |

| F04 | 프로필 기능 | 즐겨찾기 관리, 리뷰 관리 등 | 높음 |
| F05 | 리뷰 작성 | 가게별 리뷰 및 별점 기록 | 높음 |

## 🧩 API 명세 요약

| 분류 | 메서드 | 경로 | 설명 | 인증 |
|------|---------|------|------|------|
| Auth | POST | `/auth/signup` | 회원가입 | ❌ |
| Auth | POST | `/auth/login` | 로그인 | ❌ |
| User | GET | `/users/me` | 내 정보 조회 | ⭕ |
| Store | GET | `/stores` | 빵집 목록 조회 (위도/경도 기반) | ❌ |
| Store | POST | `/stores` | 빵집 제보 등록 | ⭕ |
| Review | POST | `/reviews` | 리뷰 작성 (이미지 업로드 포함) | ⭕ |
| Review | GET | `/stores/{id}/reviews` | 특정 빵집 리뷰 조회 | ❌ |
| Social | POST | `/users/{id}/follow` | 유저 팔로우/언팔로우 | ⭕ |
| Interaction | POST | `/reviews/{id}/like` | 리뷰 좋아요 | ⭕ |

**에러 응답 형식**
{ "error": "Error Message", "code": 4xx/5xx }

## 느낀점

**조하원**: 구상해왔던 주제를 기획서로 상세히 정리해봄으로써, 구현해낼 프로젝트에 대해 더 깊이 생각해볼 수 있었습니다. 필수 기능 정의 및 진행 계획 수립, 레퍼런스 서치, 목업 디자인, 데이터셋 가공 및 API 명세 작성 등을 수행해보면서 프로젝트에 첫 발을 성공적으로 내딛었습니다. 특히나 주요 관심사였던 '지도 기능'을 바탕으로, 팀메이트의 관심사인 '빵'을 결합해 함께 결과물을 만들어낼 생각에 최종 프로젝트 결과물이 기다려집니다.

**손효지**: 새로운 프로젝트를 직접 설계하고, 필요한 기능을 나열해보면서 한 학기 동안 배웠던 로직들이 떠올라 흥미로웠습니다. 또, 머릿속으로 떠오르는 기능들과 아이디어를 직접 구현해볼 수 있겠다는 생각에 굉장히 설렙니다. 특히나 주요 관심사인 '빵'을 주제로 기능들을 생성해볼 수 있다는 점, 데이터셋 확보, 전반적인 디자인 및 목업까지 작업해봄으로써 프로젝트 완성작이 더더욱 기대됩니다.

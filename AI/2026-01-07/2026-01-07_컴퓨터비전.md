# 컴퓨터 비전 (Computer Vision)

## 1. 전처리 : 기하학적 변환 (Geometric Transformations) 📐

이미지의 형태나 크기를 모델 학습/추론에 최적화된 형태로 변형

### 1-1. 크기 조정(Resizing) 및 다운 샘플링

- 개념: 입력 이미지 해상도를 모델 요구 크기(예: 640x640, 224x224)로 조정

- 목적: 연산량 감소 및 메모리 효율성 증대

### 1-2. 비율 유지 패딩 (Letterbox Padding)

- 문제점: 단순 리사이징 시 객체 비율 파괴 및 왜곡(Distortion) 발생

- 해결책: 원본 가로세로 비율(Aspect Ratio) 유지 후, 남는 여백을 특정 색상(회색/검정)으로 채움

### 1-3. 이미지 피라미드 (Image Pyramid)

- 개념: 단일 원본 이미지를 다양한 해상도로 변환(Upsampling/Downsampling)하여 계층적 구성

- 효과: 다양한 크기의 객체(Multi-scale) 탐지 성능 향상

## 2. 전처리 : 광도 및 색상 변환 (Photometric & Color Transformations) 🎨

픽셀 값을 조절하여 조명·색상 변화에 강건한 모델 생성

### 2-1. 정규화 (Normalization)

- 디지털 이미지의 픽셀 값(0~255 정수)을 수치적으로 안정화
- 스케일링(Scaling): 픽셀 값을 255로 나누어 0~1 사이 실수로 변환 (기울기 소실 방지)
- 표준화(Standardization): 데이터 평균을 0, 표준편차를 1로 조정 (분포 정렬)

### 2-2. 색상 보정 (Color Correction) 및 공간 변환

- 조명 온도, 밝기, 그림자에 의한 픽셀 값 왜곡 보정
- 히스토그램 평활화: 픽셀 분포를 균일하게 하여 명암 대비(Contrast) 향상
- 색상 공간 변환: RGB → HSV, YCbCr 등으로 변환
- 핵심: 밝기(V, Y)와 색상(H/S, Cb/Cr) 성분 분리
- 효과: 조명 변화에 민감한 밝기 정보 배제, 색상 정보 위주 학습으로 강건성(Robustness) 확보

### 2-3. 노이즈 제거 (Denoising)
- 저조도, 센서 열잡음 등 제거
- 가우시안 필터: 이미지 블러(Blur) 처리를 통해 고주파 노이즈 제거
- 중간값 필터: 주변 픽셀 중간값 선택, 소금-후추 노이즈(점 잡음) 제거에 탁월

## 3. 데이터 증강 (Data Augmentation) 전략 🧩
- 한정된 데이터에 인위적 변형을 가해 다양성 확보
- 목적: 과적합(Overfitting) 방지 및 일반화(Generalization) 성능 극대화

**<핵심 기법>**

**기하학적 변환**

- Flip : 좌우 반전(거울 모드), 상하 반전
- Rotation: 특정 각도로 회전
- Crop: 이미지 일부 무작위 추출 (객체 가림 현상 대비)

**광학적 변환**

- Color Jitter: 밝기, 대비, 채도, 색조 임의 변경

**고급 기법**
- Mixup: 두 이미지를 투명하게 겹쳐 새로운 데이터 생성
- CutMix: 이미지 일부를 잘라 다른 이미지 조각 삽입
- Mosaic: 4장 이미지를 하나로 합침 (YOLO 시리즈 핵심, 작은 객체 탐지 유리)

## 4. 추론 (Inference)
- 학습된 모델로 새로운 데이터 예측
- 핵심 지표: 정확도(Accuracy), 응답 속도(Latency), 처리량, 효율성

### 4-1. 이미지 분류 (Image Classification)
- 이미지 전체를 분석하여 미리 정의된 클래스(정답) 중 하나 할당
- 특징: 화면 꽉 찬 단일 피사체 분석에 적합

**<대표 모델>**
- ResNet: 잔차 연결(Skip Connection)로 깊은 망 학습 가능
- EfficientNet: 깊이·너비·해상도 밸런스 최적화
- ViT: 트랜스포머 구조 적용, 대용량 데이터 고성능

### 4-2. 객체 탐지 (Object Detection)
- 이미지 내 객체 종류(What) 식별 + 위치(Where) 바운딩 박스 탐지
- 대표 모델: YOLO (You Only Look Once)
- 활용: 자율주행, 지능형 CCTV, 스마트 팩토리

### 4-3. 이미지 분할 (Image Segmentation)
- 객체 탐지보다 정밀하게 픽셀 단위로 객체 구분
- 의미론적 분할(Semantic): 객체 종류별로 색상 구분 (배경 vs 객체)
- 인스턴스 분할(Instance): 같은 종류 내 개별 객체까지 구분 (사람A vs 사람B)
- 활용: 의료 영상(암세포), 자율주행(차선), 가상 배경

### 4-4. 얼굴 인식 (Face Recognition)
- 과정: 얼굴 탐지 → 랜드마크(눈코입) 정렬 → 특징 벡터 추출 → DB 대조
- 활용: 잠금 해제, 출입국 심사, 근태 관리

### 4-5. 자세 추정 (Pose Estimation)
- 개념: 관절 포인트(Keypoints) 탐지 및 골격 구조 복원
- 활용: AI 스포츠 코칭, 홈트레이닝, 제스처 UI

### 4-6. 광학 문자 인식 (OCR)
- 개념: 이미지 속 텍스트 추출
- 활용: 문서 자동화(DX), 실시간 번역, 신분증 인증

## 5. 후처리 (Post-processing) ⚙️
- 모델 출력값(Raw Data)을 사용 가능한 형태로 정제

### 5-1. 비최대 억제 (NMS, Non-Maximum Suppression)
- 중복된 박스 중 가장 정확한 하나만 남기는 기술

**<작동 원리>**
- 신뢰도 필터링: 점수 낮은 박스 제거
- 정렬: 점수순 나열 후 최고 점수 박스(주인공) 선정
- IoU 억제: 주인공과 IoU(교집합/합집합) 높은(많이 겹친) 박스 삭제

### 5-2. 임계값 필터링 (Thresholding)
- 불확실성 제거: 예측 확률이 기준치(Threshold) 이상일 때만 탐지 인정
- 효과: 오탐지(False Positive) 감소 및 정밀도 향상

### 5-3. 좌표 변환 및 스케일링
- 개념: 전처리된(리사이징) 좌표를 원본 이미지 좌표로 역변환
- 목적: 모델 시선과 사용자 시선 일치

### 5-4. 시각화 (Visualization)
- 방법: 바운딩 박스, 클래스명, 히트맵 등을 원본 위에 오버레이(Overlay)

### 5-5. OCR 후처리 전략
- OCR 출력 토큰을 의미 있는 텍스트로 변환
- 기본: 디코딩(문자열 변환), 정규화(유니코드/공백 정리)
- LLM 활용: 오타·문맥 오류를 LLM으로 교정하여 인식률 극대화

## 6. 실습 도구 🛠️
### 6-1. YOLO (Ultralytics)
- 버전: YOLO v8 (최신 v11 등)
- 특징: 탐지·분할·포즈 추정 통합 지원, 간결한 파이썬 코드

###6-2. EasyOCR
- 특징: 80+ 언어 지원, 사용 간편한 오픈소스 라이브러리

### 6-3. TrOCR
- 구조: Vision Transformer(인코더) + Text Transformer(디코더)
- 특징: CNN/RNN 미사용, 손글씨 및 복잡한 폰트 인식 우수


## 💡 정리
이번 학습을 통해, 성공적인 AI 서비스는 단순히 최신 모델(SOTA Model)을 가져다 쓰는 것만으로 완성되지 않는다는 점을 깊이 깨달음

오히려 입력 데이터의 품질을 결정하는 '전처리(Preprocessing)'와, 기계의 예측값을 인간이 이해할 수 있는 정보로 변환하는 '후처리(Post-processing)' 단계가 전체 파이프라인의 성능을 좌우하는 핵심 요소임을 알게 됨

결국 "좋은 모델은 좋은 데이터와 탄탄한 파이프라인 위에서 동작한다"는 원칙을 확인했으며, 앞으로 진행할 실습(YOLO, OCR)에서는 모델의 정확도뿐만 아니라 전체 프로세스의 효율성과 강건성(Robustness)을 확보하는 데 집중해야겠다

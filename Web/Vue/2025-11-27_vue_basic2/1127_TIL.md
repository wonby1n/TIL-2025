## 1. Vue 3 앱 기본 구조

### 1-1. CDN으로 Vue 3 불러오기

```html
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
```

### 1-2. 기본 앱 생성 패턴

```html
<div id="app">
  {{ message }}
</div>

<script>
  const { createApp, ref } = Vue

  const app = createApp({
    setup () {
      const message = ref('Hello Vue 3')

      return {
        message,
      }
    },
  })

  app.mount('#app')
</script>
```
- createApp({ ... }) : 새로운 Vue 앱 인스턴스 생성
- setup() : 컴포지션 API 시작점
- ref() : 반응형 변수 생성
- app.mount('#app') : id="app" 영역에 Vue 연결

## 2. 단방향 바인딩 – 데이터 → 화면

### 2-1. 텍스트 바인딩
```html
<p>현재 인원 수: {{ totalNum }} 명</p>
<p>총 입장료: {{ price * totalNum }} 원</p>
```
- `{{ }}` 안에는 JS 표현식 사용 가능 (단, 문(statement)은 X)
- price * totalNum 처럼 간단한 계산도 가능
### 2-2. 속성 바인딩 – `v-bind` / `:`

```html
<a :href="museumURL">전시장 바로가기</a>
<li :id="j.enTitle">...</li>
<p v-html="j.description"></p>
```
- `:href="museumURL"` : 변수 값으로 href 속성 설정

- `:id="j.enTitle"` : 전시 정보 객체의 enTitle을 id로 사용

- `v-html="description"` : HTML 문자열을 실제 HTML로 렌더링

## 3. 이벤트 핸들링 – `v-on` / `@`

### 3-1.클릭 이벤트
```html
<button @click="increaseNum">+</button>
<button @click="decreaseNum">-</button>

```
```js
const increaseNum = () => {
  j.value.totalNum++
}

const decreaseNum = () => {
  if (j.value.totalNum <= 0) return
  j.value.totalNum--
}
```
### 3-2.폼 제출 + 기본 동작 막기
```html
<form @submit.prevent="changeStyle">
  <input v-model="colorType">
  <input v-model="fontType">
  <button type="submit">변경!</button>
</form>
```
- `@submit.prevent="changeStyle"`
  - submit 이벤트 발생 시 changeStyle 실행
  - `.prevent` 로 브라우저 기본 동작(새로고침) 방지
- 버튼 클릭 + Enter 입력 모두 `submit`으로 처리 가능

## 4. 양방향 바인딩 – `v-model`

### 4-1. 텍스트 input, textarea
```html
<input type="text" v-model="formData.name">
<textarea v-model="formData.content"></textarea>
```
### 4-2. select
```html
<select v-model="inputColor" required>
  <option disabled value="">색상을 선택하시오.</option>
  <option value="red">Red</option>
  <option value="green">Green</option>
  <option value="blue">Blue</option>
</select>
```
### 4-3. checkbox (여러 개 → 배열)
```html
<input type="checkbox" value="Python" v-model="formData.languages">
<input type="checkbox" value="JavaScript" v-model="formData.languages">
```
- 체크된 값들이 `formData.languages` 배열에 쌓임
  - 예: `['Python', 'JavaScript']`
### 4-4. number 형 변환
```html
<input type="number" v-model.number="formData.age">
```
- `.number` 수식어 : 입력값을 숫자로 변환

## 5. 클래스 바인딩 – :class
### 5-1. 조건부 클래스 (객체 문법)
```html
<li :class="{ 'is-selected': j.isSelected }">...</li>

<span :class="{ 'is-required': j.totalNum <= 0 }">
  인원 수 : {{ j.totalNum }} 명
</span>
```
- `{ '클래스명': 조건 }`
  - 조건이 true → 해당 클래스 적용
  - 조건이 false → 클래스 미적용
  
### 5-2. 예시 – 전시 선택/인원수 상태
- 전시 선택 체크박스에 `v-model="j.isSelected"`
  → 체크 시 `j.isSelected === true`
  → `li`에 `is-selected` 클래스 적용 (배경색 변경)

- `j.totalNum <= 0` 일 때 `is-required` 클래스 적용
→ 인원 수 0명일 때 빨간색 표시

## 6. 스타일 바인딩 – `:style`
### 6-1. 스타일 객체와 바인딩
```html
<p :style="styleObject">Let's change the font style!</p>
```
```js
const styleObject = ref({})

const changeStyle = () => {
  styleObject.value = {
    color: colorType.value,
    fontFamily: fontType.value,
  }
  colorType.value = ''
  fontType.value = ''
}
```
- `:style="styleObject"`
  → `{ color: 'red', fontFamily: 'cursive' } `형태의 객체를 전달

- JS에서는 `fontFamily`, CSS에서는 `font-family`로 적용됨

## 7. 상태를 객체 하나로 관리하기
### 7-1. 전시 정보 객체
```js
const j = ref({
  koTitle: '모네 인사이드',
  enTitle: 'monet-inside',
  artMuseum: '예술의 전당',
  museumURL: 'https://www.sac.or.kr/',
  description:
    '<p> &lt;모네 인사이드&gt; 는 빛의 화가 <b>클로드 모네</b>가 남긴 소중한 명작들을 현대적 감각으로 재해석해 음악과 함께 감상하는 미디어아트 전시입니다. </p>',
  isSelected: false,
  price: 1000,
  totalNum: 0,
})
```
### 7-2. 템플릿에서 객체 사용
```html
<li :id="j.enTitle" :class="{ 'is-selected': j.isSelected }">
  <input type="checkbox" v-model="j.isSelected">

  <h3>{{ j.koTitle }}</h3>
  <p v-html="j.description"></p>
  <p>{{ j.artMuseum }}</p>
  <a :href="j.museumURL">전시장 바로가기</a>

  <p>가격 : {{ j.price }} 원</p>

  <div>
    <span :class="{ 'is-required': j.totalNum <= 0 }">
      인원 수 : {{ j.totalNum }} 명
    </span>
    <button @click="decreaseNum" :disabled="j.totalNum <= 0">-</button>
    <button @click="increaseNum" :disabled="j.totalNum >= 10">+</button>
  </div>
</li>

<p>총 입장료 : {{ j.price * j.totalNum }} 원</p>
```
### 7-3. 인원 수 증감 로직
```js
const decreaseNum = () => {
  if (j.value.totalNum <= 0) return
  j.value.totalNum--
}

const increaseNum = () => {
  if (j.value.totalNum >= 10) return
  j.value.totalNum++
}
```
- 최소 0명, 최대 10명 제한

- 버튼 쪽 `:disabled`와 조건을 맞춰서 UX 보완

## 8. 오늘 정리 – 패턴 요약
1. 데이터 선언
- `ref(초기값)` 또는 `ref({ ... })`

2. 데이터 → 화면
- 텍스트: `{{ 변수 }}`
- 속성: `:href="..."`, `:id="..."`, `:class="..."`, `:style="..."`

3. 화면 → 데이터 (입력)
- `v-model="변수명"`

4. 이벤트 처리
- `@click="함수명"`, `@submit.prevent="함수명"`

5. 조건부 스타일링
- `:class="{ '클래스': 조건식 }`
- `:disabled="조건식"`

6. 간단 계산/로직은 템플릿에서 바로

- `{{ price * totalNum }}`
- `:disabled="j.totalNum <= 0"`
